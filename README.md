# possibility-matrix

A convention for AI agents: when a question has more than one defensible answer, lay out the answer space as a matrix with a **Holds if** premise per row. The human picks by checking which premise is true.

- `SKILL.md` - the agent side
- `HUMAN.md` - the human side: what changes for you, how to read it, when to override
- `examples/double-tap.md` - a worked example

Peers: `learning-mode`, `translator`, `mastery`.
